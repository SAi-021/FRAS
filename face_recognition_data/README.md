# face_recognition_data/

This folder is populated automatically at runtime by the application and is **not** committed to GitHub:

- `training_dataset/<username>/` — face images captured through the "Get Dataset of New Employee" page (300 images per employee).
- `classes.npy` — label encoder classes generated during training.
- `svc.sav` — the trained SVM face-classification model, generated by the "Train Dataset" page.
- `shape_predictor_68_face_landmarks.dat` — a pretrained dlib facial-landmark model (~96 MB). It is **not included** in this repository because of its size and because it is a standard third-party file.

  Download it from dlib's official model repository and place it here:
  http://dlib.net/files/shape_predictor_68_face_landmarks.dat.bz2
  (extract the `.bz2` file so that `shape_predictor_68_face_landmarks.dat` sits directly inside this folder)

These files are excluded from version control on purpose — they contain generated/binary data and, in the case of the training photos, personal biometric data of real people that should never be pushed to a public GitHub repository.
